## Future Clutter

#### Short Game/Experience for a SoundScape Project. 
Created by Sara Johnson using p5.js

***

#### Controls:

Click anywhere on the grid to add a seed
Click on any seed to remove it

C to add a cleaner bot
X to remove a cleaner bot
V to add a trash bot
Z to remove a trash bot

R to reset game (if sound cuts out, reload the page)
